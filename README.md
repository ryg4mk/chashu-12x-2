# チャーシューメン、チャーシュー12倍 2

前作「チャーシューメン、チャーシュー12倍」をベースにしたブラウザ向け第2作。大きく薄いチャーシューをパンケーキタワーのように上へ積み重ねます。

- タップで1枚、長押しで連続投下。投下位置は左右に往復します。
- 既存の背景・ラーメン鉢・メニュー札・HUD・リザルト・料金は継承。
- チャーシューのサイズ、厚み表現、積み重ねの物理判定を第2作専用に変更。
- 最初の6枚は積み重なった状態の950円。7枚目から1枚70円。
- 直近10枚は動く状態を維持し、古い安定したチャーシューのみ固定。重心がずれると横へ滑り、支えを失うと落下します。
- 端から実際に落ちた時点でゲームオーバー。最高記録はこの第2作だけの別キーで保存されます。
- `index.html` 単体で動作。外部JS/CSSは編集用コピーです。

GitHub Pages での公開には新規リポジトリ `chashu-12x-2` を作成し、Pages を `main`/root から配信する設定が必要です。
